Anleitung

Suche

  • Lieder suchen: Einfach Text eingeben, um nach Liedern (Titel, Text, Autor) zu suchen. Gross-/Kleinschreibung wird ignoriert.
  • Suche löschen: Mit dem ✕-Button oder "Reset"

Biercomment

  • Gib "comment" ins Suchfeld ein, um den Biercomment Al! anzuzeigen

Anzeige

  • Lieder: Tippe auf ein Lied, um es anzuzeigen
  • Doppeltippen: Wechselt zwischen Fliesstext und Zeilenumbruch

  • Schriftgrösse anpassen:
        - 2-Finger-Geste (Pinch-to-Zoom) zum Vergrössern/Verkleinern oder
        - A+/A-/A Buttons am unteren Bildschirmrand

  • Favoriten verwalten: Liedtitel in der Liedansicht kurz antippen (👆) rotiert die Auswahl

  • Wähle zwischen:
        - 🎶 MeineLieder 🎶
        - 🍻 Stamm 🍻
        - 🥨 Frühschoppen 🥨
        - keine Markierung
  • Markierte Lieder erscheinen mit Emoji in der Hauptliste
  • Suche nach "meinelieder", "stamm" oder "frühschoppen" zeigt alle markierten Lieder
  • Die Daten werden im Browser gespeichert und sind nicht übertragbar.

Mitsingen-Modus

Automatische Anzeige des geteilten Liedes für Mitsinger!
- Lied teilen: Titel des Liedes nach rechts wischen (👉)
- Teilen beenden: Titel nach links wischen (👈)
- Das geteilte Lied wird mit 🔥 markiert.
- Nur der Nutzer, der ein Lied geteilt hat, kann das Teilen beenden oder ein anderes Lied teilen.
- Nach 3 Minuten wird das Teilen automatisch beendet.
- Mitsingen aktivieren: In den Einstellungen unter "Mitsingen" auf "Ein" tippen.
- Mitsingen Deaktivieren: "Mitsingen" auf "Aus" stellen, um keine Lieder zu empfangen oder zu teilen
- Die Mitsingen-Funktion geht nur mit Datenverbindung.
- Es werden keine persönlichen Daten in die Cloud gesendet. Die vorübergehend geteilten Daten sind z.B. "user_Zeitstempel_Zufallszahl", "Bier her", "Zeitstempel").

Offline-Nutzung

Die App kann (meistens) auch ohne Internetverbindung genutzt werden.

Normale Variante: Einmal laden, dann offline verfügbar

  • Öffne die App einmal mit Internet
  • Sie bleibt im Browser-Cache und funktioniert danach offline
  • Wenn beim Öffnen eine Internetverbindung besteht, lädt die App neue Versionen automatisch.
  • Browser können gespeicherte Daten jederzeit löschen, besonders nach längerer Zeit oder bei Speicherbereinigungen.

Als Datei herunterladen, falls die normale Variante nicht geht und offline wichtig ist

In Einstellungen findest du den Button "App für Offline speichern". Damit lädst du eine vollständige Offline-Datei herunter.

  1. Tippe auf "App für Offline speichern".
  2. iOS: Wähle "In 'Dateien' sichern" und speichere die Datei in einem Ordner.
  3. Android/Desktop: Je nach Browser wird die Datei direkt heruntergeladen oder es erscheint ein Dialog zum Speichern.
  4. Öffne die gespeicherte Datei später direkt aus der Dateien-App oder dem Download-Ordner.
  5. Auf dem Homebildschirm kann ein Link zur gespeicherten Datei ablegt werden, so dass sie einfach geöffnet werden kann.

Die gespeicherte Datei bleibt auf diesem Versionsstand. Für Aktualisierungen öffne die Online-App und speichere die Datei erneut.

Zum Home-Bildschirm hinzufügen

  1. Öffne Einstellungen → tippe auf "App auf diesem Gerät installieren".
  2. Chrome/Edge: Wenn der Browser einen Installationsdialog anbietet, bestätige ihn.

  3. Andernfalls zeigt die App die zum verwendeten Browser passende Anleitung an.

  4. iOS Safari: Teilen (⬆️) → "Zum Home-Bildschirm". In Chrome, Firefox oder Edge auf iPhone/iPad muss der Link dafür zuerst in Safari geöffnet werden.

  5. Android Chrome: Menü (⋮) → "App installieren" oder "Zum Startbildschirm hinzufügen"
  6. Samsung Internet: Menü (☰) → "Seite hinzufügen zu" → "Startbildschirm"
  7. Microsoft Edge: Menü (⋯) → "Apps" → "Diese Website als App installieren"

Hinweise

  • Die WebApp besteht aus einer einzigen Datei (index.html), die alle Daten enthält und im Standardbrowser geöffnet wird.
  • Die Html-Datei kann heruntergeladen und offline benutzt werden.
  • Sie kann beliebig geteilt werden, durch das Versenden der Datei oder das Teilen des Links.
  • Das Projekt ist wird auf github pages unter orums/SAT-Canten gehostet.
  • Beim Öffnen lädt die Online-App neue Versionen automatisch.
  • Korrekturen, Anregungen und neue Lieder können auf github.pages gepostet werden.
  • Auf alten Geräten kann die Anwendung langsam werden.
